# All-profile v0.1.0-beta.1

The first preview of All-profile brings the whole profile-improvement workflow into one reusable skill: understand your work, prepare clear copy, apply approved changes, and check the result.

## What you can do

- Review and write your LinkedIn, YouTube channel, Instagram, TikTok, and X profiles.
- Keep one clear message across platforms while adapting each field.
- Support your wording with real projects, experience, and accurately labeled proof.
- Use an agent with account access to apply the changes you approve.
- Get a clear record of what saved and what still needs attention.

## Get started

Download `all-profile-skill-v0.1.0-beta.1.zip`, unzip it, and copy its `all-profile` folder into your Codex project's `.agents/skills/` directory. Select the skill or mention `$all-profile` in Codex CLI/IDE. See the README for examples and account-access requirements.

The skill archive contains the instructions and supporting resources. GitHub's source archives contain the complete repository, including tests and documentation. `SHA256SUMS.txt` provides the skill archive's checksum.

## Checked for this preview

Six automated tests passed. A fresh Codex process discovered the skill correctly. Independent review, four fictional writing/reconciliation tasks, and a mocked setup task were completed. A writing issue found in evaluation was fixed and rechecked.

The mocked setup preserved paragraph breaks and handled a save timeout by checking persistence instead of saving again. No unrelated settings were changed.
