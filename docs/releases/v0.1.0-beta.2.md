# All-profile v0.1.0-beta.2

The first public beta of All-profile: review your social profiles, prepare clear copy, apply changes you approve, and check the result.

## What you can do

- Review and write LinkedIn, YouTube channel, Instagram, TikTok, and X profiles.
- Adapt one recognizable message to each platform.
- Support your wording with real work and accurately described proof.
- Use an agent with suitable account access to apply approved text and links.
- Receive a clear record of what saved, what was checked, and what remains.

## Get started

Download `all-profile-skill-v0.1.0-beta.2.zip` and unzip it. Copy its complete `all-profile` folder into your Codex project's `.agents/skills/` directory. Select the skill or mention `$all-profile` in Codex CLI/IDE. The README includes examples and account-access requirements.

The standalone archive contains the skill and its MIT license. `SHA256SUMS.txt` provides its checksum. GitHub's source archives contain the complete repository, including documentation, tests, and the cover.

## Validation and limitations

Six automated tests passed again. Earlier checks covered fresh Codex discovery, independent review, four fictional drafting/reconciliation tasks, and a mocked application task. A drafting issue found in that evaluation was fixed and rechecked. The public-release archive and checksum were checked separately.

This is a beta. Live setup needs your approval, suitable browser or connector access, and available platform controls. Other agent hosts have not been installation-tested. No ranking, reach, or sales result is promised. See `tests/VALIDATION.md` for the detailed coverage.
